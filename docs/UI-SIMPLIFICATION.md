# 工作区界面简化

日期：2026-10-13（北京时间）

开发基线：`main@c3994b72890eb17642f31e5ec8ecf60e3f17463b`

分支：`codex/simplify-workspace-ui`

## 改动目标

打开插件时，先看清应用的工作区安排；需要修改时，只处理选中的应用。

原界面把六个常用程度不同的操作、完整编辑表单、检查日志和全部撤销入口同时放在首页。用户在改一个工作区前，必须理解配置、运行状态、即时移动和诊断信息之间的关系。本次重排信息层级，沿用现有 Python 桥接和窗口管理逻辑。

## 现在如何使用

1. 首页按实际默认工作区分组展示应用。宽屏两列，窄屏一列，可滚动。搜索只筛选视图；不会修改分配。
2. 点击应用打开编辑弹层，选择工作区与再次打开的行为，然后保存。
3. 整理窗口、推荐分配、诊断、语言和停用规则等低频功能放在“更多”。

普通用户无需在首页阅读内部应用 ID、配置路径、版本、Hyprland 类型或命令输出。运行中的窗口如果不在默认工作区，应用行仍显示实际位置，避免把配置分组误当作窗口当前位置。

### 新旧对应

| 原来的呈现 | 现在的呈现 |
| --- | --- |
| 左侧应用、右侧永久配置表单 | 按工作区分组概览，点击应用再编辑 |
| 顶部六个同等醒目的操作 | 搜索、添加应用、更多、关闭 |
| 保存即整理已有窗口 | 默认仅保存；显式勾选后才“保存并移动” |
| 首页大段检查报告、版本和路径 | 简短结果或问题提示，进入“配置与诊断”查看全文 |
| 首页常驻撤销全部规则 | “更多 → 停用全部规则…”，保留范围说明与确认 |
| 全局临时工作区开关 | 各次整理分别选择，默认不勾选 |

### 工作区与行为

- 支持原有 `1–999` 编号；`1–4` 提供快捷选择，其他编号直接输入。
- 分组来自真实配置，不强制命名为 AI、开发、浏览器、通信，也不重命名 Hyprland 工作区。
- “直接切换到已有窗口”保留普通工作区中的手动位置；“先移回默认工作区，再切换”沿用 `move` 行为。
- Scratchpad 的启动与复用规则保持原有语义；详情见 [使用说明](USAGE.md)。

## 保存和移动的边界

`gui.py` 已支持 `move_existing`，本次没有修改后端协议：

```json
{
  "action": "set",
  "app_id": "selected-app",
  "workspace": 2,
  "existing_window": "focus",
  "move_existing": false,
  "include_special": false,
  "revision": "编辑开始时取得的版本"
}
```

默认“保存”更新配置与启动规则，不立即移动现有窗口。选中“现在也移动已打开的窗口”后，按钮改为“保存并移动”；该请求只整理当前应用。全局整理使用单独的 `arrange` 请求与确认框。

全局整理和单应用整理各自维护临时工作区选项。每次重新打开编辑或整理确认时，选择恢复为关闭。单应用没有勾选立即移动时，临时工作区选项不可用，也不会发送 `include_special: true`。

## 保留的交互保障

- 保存前读取 SpinBox 当前文本，避免刚输入的值尚未提交；快捷选择和切换应用都恢复正确的数据绑定。
- 未提交文本也计入未保存状态；返回、切换应用或刷新前需要明确放弃。
- 保存失败保留输入和编辑开始时的 revision。新的状态响应不会自动授予覆盖其他并发修改的权限。
- 检查报告可在编辑器上方查看；只读检查不丢弃编辑，编辑期间不可接纳外部修改。
- 无效编号与保存错误显示在当前编辑弹层，可继续查看完整详情。
- 弹层按层返回，编辑结束后恢复原应用焦点；初次打开焦点在搜索框，首个分组标题保持可见。
- 组件安装/更新、中断事务、外部草稿和问题提示仍在首页提供可操作入口。
- 忙碌时继续禁止重复提交和关闭正在执行的编辑操作。

复现命令（先安装测试所需的 PySide6；这是开发验证依赖，不是插件新增依赖）：

```bash
python scripts/verify_ui.py --theme dark --output /tmp/workspaces-ui-dark
python scripts/verify_ui.py --theme light --output /tmp/workspaces-ui-light
```

`verify_qml.py` 需要 Qt 6 的 `qmltestrunner`，也可通过 `--runner` 指定。没有系统中文字体时，`verify_ui.py --font /path/to/NotoSansCJKsc-Regular.otf` 可让测试截图使用指定字体。

预览图来自修改后的实际 QML，使用示例应用与深色、绿色米黄测试色板。插件运行时仍跟随 Omarchy 的颜色、字体、字号、边框与圆角，不会替换用户主题。

### 仍需真实桌面确认

本轮不宣称完成真实 Wayland 覆盖层、多显示器选择或第三方应用启动验收。建议在用户的 Omarchy 桌面依次确认：

1. 打开插件时首屏居中、分组标题可见，常用缩放下无横向裁切。
2. 修改一个应用并直接保存：现有窗口留在当前位置，新启动行为按设置执行。
3. 勾选立即移动：只整理此应用；特殊工作区默认保留。
4. 全局整理确认、退出弹层焦点和原菜单/快捷键复用正常。

“添加应用”和“高级设置”仍调用已有终端向导；本次没有加入原生应用选择器或拖拽操作。版本保持 RC，待桌面验收后再决定是否合并和发布。
