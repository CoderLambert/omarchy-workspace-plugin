# RC → Stable 发布验收

当前为 1.3.0-rc.2 / 公开 Beta 候选。下面的真实桌面检查尚未全部完成，不可因为单元或离屏测试通过就发布稳定版。

| 场景 | 实际桌面验收标准 | 当前状态 |
| --- | --- | --- |
| 全新安装 | Omarchy 4.0.4 的菜单、面板、后端、语言文件正确加载 | 待新机器验收 |
| 重复启动 | 连续点击与快捷键只产生预期实例，重点 Grok Bot | 待复测 |
| 跨工作区 | focus 保留位置，move 正确归位 | 旧版本有本机探测，本 RC 待复测 |
| Scratchpad | Super+S 显示 / 隐藏、重新打开、整理默认保护、显式包含可迁移 | 自动化通过，实际 RC 待复测 |
| 快捷键 | 逐项预览、默认跳过、部分确认、取消、撤销恢复原绑定 | 自动化通过，实际 RC 待复测 |
| 外部修改 | desktop 被应用更新后有明确提示，不覆盖，adopt / rollback / recover 行为正确 | 自动化通过，真实第三方 desktop 更新待复测 |
| 升级 | 旧配置保留，同版本不同代码被识别，一键同步解除写保护 | 自动化通过，实际桌面升级待复测 |
| 卸载 | 恢复入口 / 绑定，保留个人分配与语言，Git 目录按生命周期保留 | 自动化通过，实际 RC 待复测 |
| 多显示器 | scratchpad 启动上下文跟随焦点显示器，无跨屏误搬 | 待验收 |

## 发版顺序

1. RC1：三项 P1 修复及对应回归测试；CI 独立重跑并保存结果。
2. RC2：记录真实 Omarchy 4.0.4 桌面矩阵，补充截图与安装 / 升级 / 卸载结果。
3. Stable：所有阻塞项解除后统一版本、重新构建安装包、校验文件和 Release Notes，再由维护者明确发布。

CI artifacts 是测试 / 构建结果，不是 Stable Release。工作流只读仓库内容并上传 artifacts，不自动创建正式 Release。
