# 面板自动预设提供准备提示与完整结果反馈

- 日期：2026-10-13
- 分支：main
- 范围：自动预设面板流程、后端桥接、中英双语与离线载荷。

## 目的与行为

旧按钮启动独立终端后关闭面板，用户无法在原界面确认结果或刷新应用。现在先显示准备提示：建议打开常用应用，说明扫描、探测启动、工作区整理和保护边界。取消不执行；确认后保持面板并显示忙碌状态，禁止重复提交。

桥接直接执行默认不添加快捷键的 setup；成功响应携带最新状态，先刷新列表和选择，再弹出结果，显示新增/受管应用数、整理窗口数与逐项识别状态。没有可登记应用时使用不同提示。失败结果留在面板，也重新读取状态，不自动接纳外部改动。

## 限制与部署

离屏测试不代替真实 Omarchy 桌面验收。本机只同步新代码与后端，保留空应用列表，不执行自动预设，留给用户手动测试。探测可能启动应用；仍保护所有特殊工作区，默认不添加快捷键。添加应用与高级设置暂时仍通过终端完成。
