# 检查报告支持滚动和文本选择

- 日期：2026-10-13
- 分支：main
- 范围：报告区交互及发行载荷。

## 实际修改

Panel.qml 原报告区使用普通 Text，滚动内容尺寸没有明确绑定。改成只读 TextArea，显式绑定内容高度与可用宽度；增加滚轮处理，将滚动限制在报告区，支持右侧滚动条、选择复制。报告区最大高度增加到主题缩放后的 180，新文本显示后回到顶部。

tests/ui/tst_workspaces.qml 新增 80 行报告测试：滚轮移动、滚动条到底、末行可选、窄屏嵌套滚动不影响外层，以及新报告回顶。CHANGELOG.md 和 docs/USAGE.md 说明使用方式。install-omarchy-workspaces.sh / SHA256SUMS 同步离线载荷。

## 限制

上述鼠标验证在 Qt 离屏环境中运行；没有通过 GUI 自动化在真实桌面点击滚动。部署后保持用户应用配置，打开面板交由用户体验。此改动不改变应用启动、工作区分配或快捷键。
